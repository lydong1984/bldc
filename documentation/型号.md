# 按照各个型号，介绍主要功能  

这份文档列出的是 **VESC 电机控制器固件（开源电调固件）的硬件编译目标**。VESC（Vedder Electronic Speed Controller）是开源的无刷电机驱动器，广泛用于电动滑板、电动单轮车、电动自行车、机器人、农业无人机等场景。每一个"型号"对应一块特定的控制器硬件电路板，固件根据其元器件（MOSFET 耐压、电流采样电阻、驱动芯片等）做了针对性适配。

在逐一介绍之前，先说明命名规律,这样能快速读懂绝大多数型号:

- **数字组合** 通常是「最大电压 _ 最大电流」。例如 `60_75` ≈ 60V / 75A，`75_300` ≈ 75V / 300A,`100_250` ≈ 100V / 250A。
- **mk / mkiii / V2 / Rev / r2** 等是硬件版本或修订号。
- **no_limits** 是去掉了出厂默认软件保护限制的构建,允许跑到硬件极限(风险自负)。
- **0005ohm / 005ohm / 025 / 035** 指不同的电流采样电阻阻值,影响电流量程与精度。
- **ph** 常表示带相电流采样(phase current sensing)的高精度版本。

下面按系列说明各自的主要定位与功能。

这是 Benjamin Vedder 官方及其授权的主流硬件,涵盖了从入门到大功率的完整功率梯度:

## 第一步:搞清楚 `basic` 到底是什么

先纠正一个容易踩的坑:`basic` 是一个**编译目标(build target)**,不是一块你能买到的现成板子。它在源码里对应一份硬件配置头文件,定义了引脚映射、采样电阻、默认限制等。所以"用 basic 学习"通常有两种含义:

- **纯软件学习**:在电脑上把固件编译出来,读代码、改代码,不一定接真实硬件。
- **配合硬件学习**:把编译好的固件刷到一块兼容的板子上跑起来。

如果你手上**没有真实 VESC 硬件**,建议先走纯软件路线,等理解了再考虑买一块(最推荐入门买正品或 Flipsky 的 `60` / `75_300` 级别板子)。

## 第二步:搭建编译环境

VESC 固件用 ARM GCC 工具链 + Make 编译。基本流程:

```bash
# 克隆官方固件仓库
git clone https://github.com/vedderb/bldc.git
cd bldc

# 查看所有支持的板子(就是你文档里那 254 个目标)
make
```

你需要安装的核心工具:

- **arm-none-eabi-gcc**(ARM 交叉编译工具链)
- **make**
- 在 Linux/macOS 上最顺手;Windows 建议用 WSL2 或装好工具链。

然后编译 `basic` 目标:

```bash
make basic
```

成功后会在 `build/basic/` 下生成 `.bin` 固件文件。光是能跑通这一步,你就已经理解了"固件目标"是怎么从源码变成可烧录文件的。

## 第三步:读懂代码结构

编译能通过后,重点看这几个地方,理解 `basic` 这个目标是如何被定义的:

- **`hwconf/` 目录**:存放各硬件的配置。找到 `basic` 对应的硬件头文件(类似 `hw_xxx.h` 和 `hw_xxx.c`),这里定义了引脚、ADC 通道、采样电阻阻值、默认电流/电压限制。这是理解"为什么不同型号固件不同"的关键。
- **`conf_general.h` 和 `conf_default.h`**:全局默认参数。
- **`motor/` 与 `mc_interface.c`**:电机控制核心(FOC/BLDC 算法入口)。
- **`main.c`**:程序入口,看初始化流程。

建议你先**只改一个小参数**(比如默认电流限制),重新编译,观察变化,建立"改源码→编译→生效"的直觉。

## 第四步:安装 VESC Tool

无论是否接硬件,都装一下官方上位机 **VESC Tool**(官网 vesc-project.com 可下载)。它能:

- 连接真实硬件做电机检测、参数配置;
- 实时看波形(电流、转速、温度);
- 写 LispBM 脚本做扩展逻辑。

即使没硬件,熟悉 VESC Tool 的界面也能帮你理解固件里各个参数的实际意义。

## 第五步:如果有硬件,跑通"点亮"流程

接上兼容板子后的标准流程是:

1. 用 VESC Tool 通过 USB 连接,确认能读到固件版本;
2. 跑 **Motor Setup Wizard**,让固件自动检测电机参数(R、L、磁链);
3. 设置电流/电压限制(新手务必从保守值开始);
4. 用键盘或遥控输入测试转动。

⚠️ 提醒:`basic` 的默认采样电阻和引脚配置不一定匹配你的实际板子,**直接刷错配置可能烧板甚至烧电机**。所以如果买了具体型号的板子,应该刷对应型号的固件目标,而不是 `basic`。`basic` 更适合在仿真/学习阶段使用。

## 学习节奏建议

我的建议是分三个阶段:**先纯软件**(编译通过 + 读懂 hwconf 结构),**再上位机**(玩熟 VESC Tool 和参数含义),**最后真实硬件**(用对应型号固件跑电机)。把每一步吃透再进下一步,会比一上来就接电机安全也高效得多。
